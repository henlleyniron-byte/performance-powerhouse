Pathway map

Use after attempting
Gs

↑ Adenylyl cyclase → ↑ cAMP → PKA. Examples: β₁, β₂, β₃, H₂, D₁, V₂.

Gi

↓ Adenylyl cyclase → ↓ cAMP. Examples: M₂, α₂, D₂.

Gq

PLC cleaves PIP₂ → IP₃ + DAG. IP₃ releases ER Ca²⁺; DAG supports PKC activation. Examples: α₁, M₁, M₃, H₁, V₁.

NO → cGMP

NO activates soluble guanylyl cyclase → ↑ cGMP → PKG → vascular smooth-muscle relaxation.

Retrieval rule: say receptor → G protein/effector → second messenger → kinase/ion → response before reading the explanation.
