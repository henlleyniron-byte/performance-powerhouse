Gs

↑ adenylyl cyclase → ↑ cAMP → PKA. β₁, β₂, β₃, H₂, D₁, V₂.

Gi

↓ adenylyl cyclase → ↓ cAMP. M₂, α₂, D₂.

Gq

PLC → PIP₂ cleavage → IP₃ + DAG → Ca²⁺ / PKC. α₁, M₁, M₃, H₁, V₁.

cGMP

NO → soluble guanylyl cyclase → cGMP → PKG. ANP uses membrane guanylyl cyclase.
