# Roadmap

This roadmap is intentionally small. The project should improve evidence quality without becoming another high-maintenance productivity system.

## Near term

- Improve first-run explanations for new students
- Expand accessibility checks for keyboard navigation and screen-reader labels
- Add stronger import validation for malformed backup files
- Add lightweight automated smoke tests for the core repair/retest workflow
- Improve mobile layout edge cases
- Document the Physics Intelligence classification workflow more clearly

## Maintenance principles

- Prefer bug fixes and evidence-loop improvements over feature accumulation
- Keep the default app local-first and dependency-light
- Do not add copyrighted question-paper dumps
- Do not require accounts or cloud storage for the basic workflow
- Treat any off-device data transmission as a privacy-sensitive architectural change
