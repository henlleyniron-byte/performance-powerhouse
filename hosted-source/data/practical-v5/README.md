# Practical Mastery V5 authored sources

The subject case JSON files are the canonical editable V5 source. Source audit notes record the NIE handbook inspection; legacy and V4 audit JSON record checks and explicit correction proposals. Do not edit historical V3.1–V4 public banks in place.

Rebuild content with `python scripts/assemble-practical-v5.py`, then `node scripts/export-practical-v5.mjs`. Rebuild PDFs using the primary Python runtime with ReportLab and PyMuPDF: `python scripts/build-practical-v5-pdfs.py`. That step requires the user-supplied 403-page V4 PDF at `../practical-v5/input/v4_complete.pdf`; its SHA-256 is recorded in the release report. Original uploads remain unchanged.
