# Performance Powerhouse V15 — Evidence Trail

## What changed

- Command now presents one useful next evidence action from the existing repair board, with a direct trail inspector and access to all review records.
- Each repair record can explain its linked source, diagnosis, targeted repair, unaided reattempt, fresh transfer, delayed check and scope confirmation. It exposes specific deficiencies such as guesses, audited lost marks, assisted work, reused references and early dates.
- The existing verifier still decides the overall status. Its later-failure result now includes the blocking attempt ID so the trail can show the actual record that reopened the chosen weakness. No passing criterion changed.
- Verification editing retains in-tab drafts across background refresh, source switching and Share-safe toggles. A stored-value comparison blocks stale saves before recovery or current-ledger writes. Cross-tab notifications pause saving and preserve drafts for private export and comparison after reload.
- Draft export is explicitly unsubmitted text. It has no evidence credit and does not silently restore or overwrite the ledger. Existing ledger imports and storage namespaces remain unchanged.
- Original stored data that is malformed is treated as recovery material rather than as a fresh empty ledger. Private review and trail dialogs clear their visible content in Share-safe mode.

## Validation

Production Worker build, artifact validation, JavaScript syntax checks and whitespace checks passed. Full regression run with the optional DOM test package supplied: 216 tests, 170 passed, zero failed, 46 skipped because unrelated private source fixtures were unavailable.

Twelve new checks cover chain explanations, exact reopening evidence, pagination, query filters, complete brief text, clipboard failure, private cleanup, draft preservation, stale-save rejection, cross-tab notifications and successful commits. Interaction checks use a synthetic DOM with native-control shims; they are not real-browser rendering tests. No personal cloud records were accessed or changed.

The browser could list its tabs but repeatedly failed to reconnect with an Emulation.setFocusEmulationEnabled timeout. Real-browser visual, keyboard and file-download interaction for this release remains unverified. The inspected text, action wiring and export payloads passed DOM-level checks.

The compare-before-write guard is not a transactional cross-tab locking protocol. Drafts remain in memory until exported or saved; closing the tab can discard them. No database migration or automatic cloud synchronization was added.

## Reproduce DOM checks

Install linkedom 0.18.12 into a temporary test-only directory. Set DOM_QA_PACKAGE to the absolute path of its esm/index.js, then run:

    DOM_QA_PACKAGE=/absolute/test-only/node_modules/linkedom/esm/index.js node --test tests/*.test.mjs tests/*.test.cjs

The package is not an application dependency and is not shipped to visitors.
