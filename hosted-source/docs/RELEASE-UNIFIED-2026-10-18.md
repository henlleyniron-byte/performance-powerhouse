# Powerhouse V13 — Unified Command & Practice

Command Centre's daily direction, intended output, weekly adjustment and optional subject notes now live beside the original Powerhouse evidence ledger. These are planning fields, not marked evidence. The existing practice, diagnosis, repair, transfer and retest tools remain intact.

The private companion remains available at its original URL and audience. Browser storage is separate between the two origins: existing private plans are not copied automatically. Export a version-one plan from the companion, open Command in Powerhouse, expand the portability controls and review the file before applying it. The default mode fills empty fields; replacement is an explicit choice.

The shared plan controller preserves the existing version-one format. It checks the current stored bytes before each save/import, rejects stale-tab overwrites, retains previous saved bytes and the current draft on reviewed import, exports unreadable originals unchanged, and exposes recovery-copy exports. The plan is browser-local and has its own export; it is not included in the existing cloud evidence backup.

Share-safe hides the new plan and disables plan export/edit actions. The phone header is compact and all primary navigation sections are reachable without horizontal scrolling. No personal plan or private tool directory was embedded in the public source.

Verification: production build, six new plan compatibility/conflict/recovery checks, six summary checks and thirteen existing evidence/reliability/recovery checks. Isolated browser tests exercised actual companion export to Powerhouse, import preview, fill-empty behavior, cancellation, invalid imports, concurrent tabs, exact unreadable-byte export, subject launch, Share-safe and three layout sizes. No personal cloud records were used for testing.

Project ID, hosting configuration, lockfile, evidence schema and existing storage namespaces are preserved. The previous saved Sites version and source commit remain available for rollback.
