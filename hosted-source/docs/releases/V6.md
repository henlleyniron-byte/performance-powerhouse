# Performance Powerhouse V6

## Daily use

1. Start from Command. Do one timed closed-book attempt, then mark it strictly.
2. Log the question reference, raw score, optional trusted score, duration, confidence, guesses, error family and one prevention rule.
3. Use Evidence to search, filter, edit or export attempts. Correcting or deleting evidence recalculates dependent retest closure.
4. Use Repairs for fresh transfer, then delayed retesting. Delayed closure requires a successful different transfer question; a fresh delayed question must also differ from both earlier references. A late transfer pushes the delayed due date to at least four days after it.
5. Copy the rolling seven-day review or a Mistake Storage Unit correction. Metrics describe logged questions; they do not predict an exam grade.

## Saving and recovery

The original browser keys and modules are preserved. Sign in with ChatGPT and choose **Connect evidence** on Command to review the local and cloud copies. The selected copy becomes the working evidence snapshot. Subsequent changes save automatically. Every server read/write is scoped to the signed-in identity. An atomic revision check rejects stale device writes and offers both copies for review.

Cloud saving covers the core profile, attempts, retests, ratings, syllabus progress, daily outputs, audits and evidence-loop checklist. The existing Study Tracker retains its separate sync and export controls. Focus timer continuity is device-local.

Export JSON periodically for an independent backup. Data & backup also exposes recovery snapshots created before imports, resets, corrections or cloud restoration. Restoring a recovery snapshot preserves the current browser copy as another recovery point.

Share-safe mode hides the detailed personal working surfaces and disables the new personal exports. It is a screenshot aid, not an access policy.
